# Nyanco 言語リファレンス

Nyancoのプログラムは、値をスタックに積む処理と、スタックから値を受け取る処理を組み合わせます。[型の詳細](TYPE_SYSTEM.md)、[標準ライブラリ](STANDARD_LIBRARY.md)、[実行とコード生成](TOOLCHAIN.md)はそれぞれ別のページにあります。

## 実行順と節

空白で並んだ項は、先頭以外を左から右に実行した後、先頭を実行します。`f x y` は `x`、`y`、`f` の順です。この規則は先頭が変数やリテラルの場合にも適用されます。変数やリテラルを先頭にすると警告 `W001` が出るため、値を記述順に積むにはコンマを使います。

`,`、`;`、改行はいずれも処理を順に進めます。`;` と改行は新しい**節**を始め、コンマは同じ節を続けます。行末の `\` は直後の改行を無視します。`--` から行末まではコメントです。

`_n` は、節に入った時点でスタックの先頭から `n` 番目の値を取り出します。`$n` は同じ位置の値をスタックに残します。添字を省略すると `0` です。同じ位置を何度参照しても同じ値を使い、取り出しは一度だけです。同じ節の同じ位置に `_n` と `$n` は混在できません。

```text
3, 4; _, _             -- スタックは 3, 4, 4
3, 4; _ * _            -- スタックは 3, 16
3, 4; $1               -- スタックは 3, 4, 3
```

括弧、vector、record、tupleは外側の節を共有します。quotationは独自の節を持ちます。quotation内の `__` と `$$` は1つ外側の節を参照し、`___` なら2つ外側です。例えば `3; {__}` は、ブロックを作るときに `3` を取り出して保持します。

## 演算子

空白による適用は二項演算子より強く結合します。二項演算子の明示的な各辺は、外側のスタックを消費せず、値を1つ生成する式です。欠けた項には、`_` と `$` の捕捉を済ませた後、スタックの値を左の項から順に当てます。

```text
f x + y                -- (f x) + y
5; 4 +                 -- 9
3, 4, 5; + *           -- 3 + 4 * 5
3 < x <= 4             -- x を一度だけ評価する比較の連鎖
```

二項演算子の優先順位は、上の行ほど強くなります。`^` は右結合です。比較の連鎖は、比較が偽になったところで評価を打ち切ります。

```text
^
*  /  %
+  -  ++
.<<.  .>>.
::
..  ..=
.&.
.|.
==  /=  <  <=  >  >=
&&
||
??
```

`&&` と `||` は右辺を短絡評価します。`??` は左辺が `None` または `Err` の場合だけ右辺を実行する `unwrapOrElse` の糖衣です。`.&.`、`.|.`、シフトは通常の二項演算子です。二項演算子よりコンマが弱く、`;` や改行は節の区切りになります。

## 関数と変数

`name pattern ... = body` で関数を定義します。引数はスタックからパターンで受け取り、残ったスタックで本体を実行します。同名の定義に複数の節を書き、`| 条件` でguardを付けられます。パターンとguardを上から順に試します。guardは値を1つも消費しない必要はなく、成功した場合は判定用のboolを取り除いたスタックで本体へ進みます。

```nyanco
absolute n | n < 0 = 0 - n
absolute n = n

main = print (absolute (-7)) -- 7
```

関数はローカルにも定義できます。`;;` で定義の終わりを明示できます。型注釈は `name : 入力 -> 出力` と書きます。

`-> pattern` はスタックから値を取り出して変数を束縛します。`pattern <- 式` と書くこともできます。変数は既定で不変です。`mut` を付けた変数や関数引数は、その型を維持したまま再代入できます。

| 書き方 | 動作 |
| --- | --- |
| `3 -> x`、`x <- 3` | 新しい不変変数を宣言 |
| `0 -> mut x`、`mut x <- 0` | 新しい可変変数を宣言 |
| `x <<- expr` | 右辺を独立したスタックで評価して代入 |
| `expr ->> x` | 現在のスタックの先頭を取り出して代入 |
| `x ! commands` | 現在のスタックに `x` を積んで右辺を実行し、先頭の結果を代入 |

`!` の右辺は新しい節です。先頭の結果を代入した後、ほかの値はスタックに残ります。`x, y <<- y, x` や `x, y ! _, _1` は、右辺を最後まで評価してから、更新値をスタック上の順に各変数へ割り当てます。`<<-` と `!` の右辺にコンマで処理を並べられます。束縛や再代入に続けて別の処理を書くときは `;` または改行で区切ります。

```nyanco
main =
    [] -> mut acc
    [1, 2, 3]; each {acc ! vpush}
    print acc -- [1, 2, 3]
```

`acc ! vpush` のように更新の先頭で要素引数を省略した場合は、もともとのスタックの先頭を追加する要素にします。`qpush`、`qpushFront`、`hpush`、`sinsert`、`sremove` も同様です。

## Quotationと制御

`{commands}` は処理を値として保持するquotationです。`call` で実行し、`compose first second` で実行順に合成できます。`do` の後にインデントした本体を書くこともできます。

```nyanco
main =
    [1, 2, 3]; each do -> x
        print (x * 2)
```

`each xs below` のように、呼び出しの引数に `below` を1つ置くと、呼び出しを終える改行や `;` から現在のブロックの末尾までをquotationにして渡します。`each` は要素を積んで現在のスタック上でコールバックを実行します。`if condition yes no` は片方のquotationを選び、`when condition body` は真の場合だけ実行します。`while condition body` は条件のquotationが真を返す間、処理を繰り返します。`loop body` は中断するまで繰り返します。

## 値とリテラル

| 値 | 表記例 |
| --- | --- |
| 整数、浮動小数点数、真偽値 | `42`、`3.5`、`True`、`False` |
| 文字、文字列 | `'猫'`、`"Nyanco"` |
| vector、tuple | `[1, 2, 3]`、`#(1, "猫")` |
| record、辞書 | `{name: "Nyanco", age: 3}`、`[0: "zero", 1: "one"]` |
| 空のvector、record、辞書 | `[]`、`{:}`、`[:]` |
| 範囲 | `1 .. 5` は終端を除き、`1 ..= 5` は終端を含む |

vectorとtupleの本体は空のスタックで実行され、残った値が要素になります。vectorの要素は同じ型にそろえます。`xs :: x` は `Push xs x` と同じ末尾追加で、`++` はvector同士や文字列同士を連結します。

型名は小文字で始まります。`int`、`float`、`byte` は別の型です。算術演算の両辺は同じ型にそろえ、必要なら `int` や `float` で明示的に変換します。整数の `/` は商を0方向に丸めます。`byte` は0から255、`char` は1つのUnicodeスカラー値、`string` はUTF-8文字列です。整数リテラルは文脈に従い、型が決まらなければ `int` になります。

文字列の `{expr}` は式の結果を埋め込み、`{}` はスタックから値を受け取ります。`\{` と `\}` で波括弧をエスケープできます。

```nyanco
main =
    print "2 + 3 = {2 + 3}"
    4, 5; print "{} + {}"
```

## アクセスとコピー更新

`r.name` はrecordのフィールド、`t.0` はtupleの先頭を読みます。`.name` や `.0` を単独で書くと、スタックの値を受け取るアクセサーになります。`{:name, :age}` は `{name: name, age: age}` の省略形です。

`xs.[i]` は0始まりの添字で、辞書の場合はキーでアクセスします。vectorでは `-1` が末尾、`-2` がその一つ前です。`.?[i]` または `tryAt xs i` は失敗時に `None`、成功時に `Some value` を返します。`.[i]` ではアクセスの失敗が `exn` になります。文字列の添字はUTF-8の `byte` を返します。

スライス `xs.[a:b]` は開始位置を含み、終端を含みません。`xs.[a:]` は末尾まで、`xs.[:b]` は先頭から切り出します。負の端点はvectorの末尾を基準に数えます。たとえば `[0, 1, 2, 3].[1:-1]` は `[1, 2]` です。

`updateAt xs i {f}` は要素にquotationを適用して更新後のコンテナを返します。`tryUpdateAt xs i {f}` は添字が見つからなければ元のコンテナを返します。どちらもquotation自身が起こしたエフェクトを呼び出し元に伝えます。

`with` は指定した箇所を更新した値を作ります。`with x = value` のように1箇所だけ書くか、`with {x = value; y ! commands}` のようにまとめます。`with` の左辺を省略すると、スタックの値を更新します。パスにはフィールド名、tupleの位置、添字を組み合わせられます。

```nyanco
main =
    r <- {name: "Nyanco", scores: [10, 20]}
    r with scores[1] ! + 2 -> updated
    print r.scores       -- [10, 20]
    print updated.scores -- [10, 22]
```

`with ?[i] ! commands` は要素があるときだけ更新し、`with [key] ??= value` はキーがないときだけ挿入します。条件付きの `!` は更新を行う場合と省略する場合でスタックの型をそろえます。可変変数には `r.name <<- value`、`r.scores.[1] ! commands`、`d.[key] ??<- value` と直接書けます。

## データ型とパターン

`data` で代数的データ型を、`type` で型エイリアスを定義します。`data box 'a = Box 'a` のように型引数やフィールドは名前の後に書きます。コンストラクタ名は大文字で始まります。`deriving show, eq, hash, ord` で、フィールドの型が必要な制約を満たす場合にインスタンスを生成できます。

パターンは関数引数、`case`、変数宣言で使えます。`_` は値を捨て、`~` は値をスタックに積みます。`#(x, y)` はtuple、`[a, b]` は固定長のvector、`{name: x}` は指定したフィールドを持つrecordにマッチします。`{:name}` で同名の変数に束縛できます。

```nyanco
pick = case
    -> [x, 0] || [0, x] ? x
    otherwise drop; 0

speak {name: ~} = print

main =
    print (pick [0, 7])
    speak {name: "Nyanco", age: 3}
```

`case` は `-> pattern ? body`、`-> pattern | guard ? body`、`| guard ? body`、`otherwise body` を上から試します。`end` で範囲を明示できます。枝のパターン数は異なっても構いませんが、戻る枝は同じ型のスタックを返します。`p || q` のパターンは左から試し、両側で束縛する名前・型・可変性と `~` の個数をそろえます。

`Push xs x` や `xs :: x` は末尾要素を分解するパターンとしても使えます。`[1, 2] ++ middle ++ [3]` は前後が一致するvectorの中央部分を束縛します。`++` で長さの決まっていない部分は1つまでです。

## 型クラス

`class` でメソッドと関連型を宣言し、`instance` で型ごとの実装を定義します。`=>` の左側には必要なクラス制約を並べます。

```nyanco
class unpack 'c where
    type item
    unpack : 'c -> item

data box 'a = Box 'a

instance unpack (box 'a) where
    item : 'a
    unpack (Box x) = x

unpackValue : unpack 'c 'a => 'c -> 'a
unpackValue = unpack

main = print (unpackValue (Box 42))
```

関連型は対象型から定まり、制約には対象型に続けて関連型を宣言順に書きます。`class show 'a => named 'a where` のようにクラスを継承できます。メソッドや演算子に必要な制約は型推論でも求められます。スタック行、型変数、エフェクト行の注釈は[型システム](TYPE_SYSTEM.md)を参照してください。

## エフェクトとハンドラー

`effect ask : -> int` は値を1つ返す操作、`effect fail : string -> !` は正常に戻らない操作を宣言します。`effect name ... where` で操作をまとめると、操作間で型引数を共有できます。

```nyanco
effect state 'a where
    ask : -> 'a
    write : 'a ->

main =
    0 -> mut value
    handle {write 42; ask} {
        ask: {-> k; resume value k},
        write: {-> next, k; value <<- next; resume k}
    }
    print -- 42
```

`handle body handlers` は `body` を空のスタックで実行し、結果を呼び出し元のスタックに積みます。ハンドラーには操作の引数と継続が渡されます。`resume` は操作の結果を継続に渡して再開します。継続は有効な間に一度だけ再開でき、ハンドラーが再開せずに返れば残りの計算を打ち切ります。ハンドラーと本体が返すスタックの型は一致させます。ハンドラー自身が起こす操作は外側で扱います。

たとえば `catch` の推論型では、受け取るquotationに `{exn | 'e}`、呼び出し側には `{ | 'e}` と表示します。入力側の `exn` はハンドラーが処理できる操作を表し、`exn` を起こさないquotationも渡せます。

`/ {io}` や `/ {state int}` は型のエフェクト行です。組み込みの `read` は標準入力から1行を読み、`put` は文字列を改行付きで出力します。`print` は値を整形して出力します。これらは `io` として型に現れます。

`break` は現在のスタックを結果として反復を終了します。その型は反復の通常の結果と一致する必要があります。`cancel` は中断された反復の途中のスタックを破棄し、ループが保持している状態や途中結果を返します。実行済みの入出力や変数への代入は取り消しません。

```nyanco
main =
    0; while {True} {+ 1; when ($ > 3) {break}}
    print -- 4
```

`loop @outer {...}` や `handle @outer {...} handlers` はquotationにラベルを付けます。`each xs @outer below` のように、`below` で作るquotationにも同じ位置にラベルを書けます。`cancel@outer`、`ask@outer`、`yield@outer` のように操作の宛先を指定できます。`mask ask {...}` はそのブロックから出る `ask` に対して最も内側のハンドラーを1つ飛ばし、`mask ask@outer {...}` は宛先を指定します。

## 可変借用

`borrow mut x as r {...}` は `x` をスコープ内で排他的に借用します。元の変数に直接アクセスする代わりに、`readRef r` と `writeRef r value` を使います。参照の型は `mutref 'r 'a` で、アクセスは `borrowMut 'r` として型に現れます。借用はスコープの外へ持ち出せません。参照を保持するquotationやstreamを外へ返す場合も同じです。

```nyanco
main =
    mut x <- 10
    borrow mut x as r {
        writeRef r (readRef r + 1)
    }
    print x -- 11
```

## モジュール

同じディレクトリにある `.nyan` ファイルが1つのモジュールです。`import "./math"` はモジュールを読み込み、`math.square` のような修飾名で参照します。`as` で修飾名を変更できます。importはファイル単位、定義の共有と公開範囲はモジュール単位です。循環importは認めません。

| 宣言 | モジュールの外から使えるもの |
| --- | --- |
| `pub f : int -> int` | 型を明示した関数 `f` |
| `pub data box 'a = Box 'a` | 型 `box` |
| `open data box 'a = Box 'a` | 型 `box` とコンストラクタ `Box` |
| `pub type token = int` | 抽象型 `token` |
| `open type token = int` | 型 `token` とエイリアスの実体 |
| `pub class ...`、`pub effect ...` | 公開したクラス・メソッド、またはエフェクト操作 |

モジュールと同名の公開型は、型を書く場所で `box.box int` を `box int` と省略できます。`pub import` で名前を再公開でき、個別の名前を選ぶ場合は `{name as alias}` と書けます。`std.prelude` は暗黙に読み込まれます。[モジュールの実行例](../examples/modules/)も参照してください。
