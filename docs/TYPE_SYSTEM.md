# 型システム

Nyancoの型検査は、Hindley–Milner方式の一般化・インスタンス化と単一化を基礎にします。関数が消費する値、生成する値、実行時に起こり得るエフェクトを型で表します。[言語リファレンス](LANGUAGE.md)に構文と実行例があります。

## スタック効果

```text
square : int -> int
swap   : ..s 'a 'b -> ..s 'b 'a
```

`->` の左が入力、右が出力です。それぞれスタックの底から先頭の順に書きます。`..s` は処理の下に残る任意個の値を表すスタック行です。例えば `swap` は上の2値を入れ替え、その下は保持します。`-> !` は正常に戻らない処理を表します。

明示的なスタック行は入出力の先頭に1つずつ書き、同じ名前を使います。`..s int -> ..s int` は有効ですが、`int ..s` や `..s ..t` は無効です。戻らない関数の出力は `!` なので、出力側に行を書きません。quotationの型にも同じ規則が適用されます。

`{int -> int}` はquotationの値型です。`continuation {int -> int}` は、再開時に `int` を受け取り、再開した計算が `int` を返す継続を表します。`stream int {-> / {io}}` は、走査時に `io` を伴う整数のstreamです。

## 推論と多相性

呼び出しのたびに関数の多相型を具体化し、現在のスタックと入力型を照合して出力型へ進みます。入力の足りない演算子やスタック参照も必要な入力として推論します。比較の連鎖では隣り合う値の型を照合します。明示的な二項演算子の辺は、外部のスタックを消費せず値を1つ返す必要があります。

不変の束縛や関数は、環境に固定されていない型変数を一般化できます。可変変数の型は一般化されず、書き換えても型は変わりません。整数リテラルの型が確定しなければ `int` を使います。明示的に数値の型を多相にするには、例えば `fromInt 0` を使います。

公開する通常の関数には型注釈が必要です。公開するクラスのメソッド、エフェクト操作、データコンストラクタの型は各宣言が与えます。

## 複合型と行多相性

`[int]` と `vector int` は同じ型です。tupleの各位置は別の型を持ち、例えば `#(int string)` と書きます。ADTは型名と型引数で区別します。

record型では、`{name: string | 'r}` のように必要なフィールドと残りの行を分けられます。フィールドアクセスやrecordパターンを使う関数は、指定したフィールド以外を持つrecordにも適用できます。値型、スタック行、record行、tuple行、エフェクト行は異なる種類の型変数です。

## クラス制約

`add 'a => 'a 'a -> 'a` は、`add` の実装を持つ型を使う関数です。標準の比較演算子 `==` は `eq` を要求し、順序比較の `ord` は `eq` を継承します。通常のquotationは等価比較できません。`num` は算術と変換をまとめたクラスで、個々の関数は使用する演算に応じた制約を推論します。

関連型はインスタンスの対象型から定まります。`streem 'c 'a` では `'c` が列の型で、`'a` が要素型です。`into 'a 'b` のように複数の型引数を持つ一般のクラスでは、両方の型がインスタンス選択に関わります。選択に必要な型が特定できない場合は型注釈で指定します。

## エフェクト行と借用

`/ {io, exn}` は外側へ伝わり得るエフェクトを表します。`/ {}` はエフェクトを外へ伝えない契約です。`/ { | 'e}` は任意の行を表し、`/ {'e}` とも書けます。エフェクト行を省略すると推論します。quotationを作っただけではエフェクトは起きず、実行する処理に伝わります。

```nyanco
run : {-> / {'e}} -> / {'e}
run q = call q

main = run {print "hello"}
```

この定義は任意の `'e` に対して成立する必要があります。`run` 自身に `print` を追加して `'e` を `io` に固定することはできません。呼び出し側では渡すquotationに応じて具体化します。

グループ化したエフェクトは型にグループ名で現れ、操作ごとにハンドラーで処理できます。ハンドラーが処理した操作は外向きの行から除かれますが、ハンドラー自身が起こすエフェクトは外側へ伝わります。ループは処理できる `break` と `cancel` を行から除きます。

可変借用の `mutref 'r 'a` と保護された `borrowMut 'r` は、同じ借用の識別子を共有します。借用中の元変数へのアクセスや、参照を含む値・quotation・遅延streamが借用範囲の外へ出ることは型エラーになります。`borrowMut` をユーザーのハンドラーで除くことはできません。
